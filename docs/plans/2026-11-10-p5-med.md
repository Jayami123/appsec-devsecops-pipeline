#### 3c.1 P5-MED-AUTHZ-001 (REFRAMED) — `tests/integration/med/cart-other-customer.spec.ts`

- **Setup:** throwaway customers A and B; two guest carts C1 and C2 created with `POST /store/carts` (no customer).
- **Control (first, independent fixture C1):** A claims C1 with `POST /store/carts/C1/customer` and A's token. Expected 200. `GET /store/carts/C1?fields=customer_id` then shows A. Before: `customer_id` null. After: A.
- **Negative (independent fixture C2):** A claims C2 (setup, state → A). Then B posts `POST /store/carts/C2/customer` with B's token.
- **Before and after:** C2 `customer_id` and `email` read before and after B's call.
- **Oracle:** PASS when B's call is refused (4xx) and C2 still shows A with A's email. PRODUCT BUG (SUSPECTED) when B's call returns 200 and C2 shows B. Any other outcome is TEST BUG or ENV (AGENTS.md).
- **Why the control is a guest cart:** the transfer does nothing when the cart already belongs to the caller (`transfer-cart-customer.ts:101-104`), so A's own repeat call cannot be a control.
- **Budget:** none (synchronous, MP:974 budget "none").
- **Cleanup:** carts are left in place under the run prefix (whether `POST /store/carts` accepts `metadata` is UNVERIFIED); the sweep reports them.
- **Verdict type:** PASS or PRODUCT BUG (SUSPECTED) (MP:144).
- **Tests (exact names):** "P5-MED-AUTHZ-001 control: a guest cart claimed by its owner moves from no customer to that customer"; "P5-MED-AUTHZ-001 a second customer cannot move a claimed cart to itself".
- **Skeleton:**

```ts
test("P5-MED-AUTHZ-001 a second customer cannot move a claimed cart to itself", async ({ request }) => {
  const a = await createThrowawayCustomer(request, { runPrefix, label: "authz1a", publishableKey });
  const b = await createThrowawayCustomer(request, { runPrefix, label: "authz1b", publishableKey });
  const cart = await createGuestCart(request, publishableKey);
  try {
    await claimCart(request, cart.id, a.token, publishableKey);            // setup: owner A
    const before = await readCart(request, cart.id, publishableKey);
    const attempt = await claimCart(request, cart.id, b.token, publishableKey);
    const after = await readCart(request, cart.id, publishableKey);
    expect(before.customer_id).toBe(a.customerId);
    if (attempt.status() === 200) {
      expect.soft(after.customer_id, "PRODUCT BUG (SUSPECTED): claimed cart moved").toBe(a.customerId);
    } else {
      expect(attempt.status()).toBeGreaterThanOrEqual(400);
      expect(after.customer_id).toBe(a.customerId);
    }
  } finally {
    await runAllThenRethrow([]);
  }
});
```

The skeleton shows the shape only. The build decides the assertion form after the live control runs, and never converts a suspected defect to PASS.
