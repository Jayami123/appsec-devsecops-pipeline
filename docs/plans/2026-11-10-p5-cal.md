## 5. Per-row design

### 5.0 Shared rules (every row)
- Setup: throwaway actors only, created per run with the run prefix from `currentRunPrefix` (`src/kit/run/prefix.ts:43`). A run prefix matches `^p5-qa-\d{8}t\d{6}z-[0-9a-f]{8}$`.
- Control first: the independent valid control runs before the negative step, with the same actor and resource class (MP section 19 intro: `MP@298ae29:916`, current 935).
- Before and after state captured for each mutation.
- Cleanup in `finally`: `runAllThenRethrow` (`src/kit/shared/cleanup.ts:18`). Revoke every created token and API key before harness `down` (`MP@298ae29:354`). Then a sweep and a leak check.
- Budget: named constant from `src/security/budgets.ts`; never a bare number (`MP@298ae29:511`).
- Verdict: PASS, PRODUCT BUG (SUSPECTED), deployment finding, design verdict, gated, or not run. A test that cannot prove its property reports gated, never PASS.
- Live rows cannot run until the stack is up (Docker). This PR runs none.
